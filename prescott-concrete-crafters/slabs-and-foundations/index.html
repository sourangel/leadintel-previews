What's included.

Around Prescott, a slab has to account for frost, which is why local code sets how deep footings must go, and for soil that ranges from loose granite to clay that swells when wet. A building pad that moves will crack whatever is built on it. Plans, inspections and a firm base come before the pour.

  • Slabs on grade for barns, shops, garages and outbuildings
  • Footings where the plan or local code calls for them
  • Base prep and forms set to line and level
  • Steel placed where the plan calls for it
  • Screeding, floating and finishing
  • Curing before anything heavy goes on it

Slabs and foundations questions.

Do I need a permit for a slab?

Often, yes, especially if a structure will go on it. The City of Prescott, the Town of Prescott Valley and Yavapai County each handle their own, so check which applies to your address.

How deep do footings need to be here?

Local code sets a frost depth, and it can differ between jurisdictions in the area. Your plans or building department will give the number for your site.

How long before I can build on a new slab?

Concrete keeps gaining strength for about 28 days. Your builder or engineer decides when it can take load.
